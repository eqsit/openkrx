# Пресет Avoid

`OpenKRX-avoid-preset.cfg` — сохранённые игровые настройки автора из обычного
OpenKRX на 2026-11-04. Выбран Blatant: check/kick 27/27, FOV 360,
64 сегмента; Avoid и Grenade Save включены. Сохранены настройки остальных
агентов, ESP, предсказания и возврата оружия. AntiPing включён,
Prediction margin — 20 мс.

Скачайте файл из Assets релиза v0.1.9 и положите рядом с папкой `data/`
распакованного клиента или в папку настроек DDNet. Затем выполните в F1:

```text
exec OpenKRX-avoid-preset.cfg
```

Пресет применяется по этой команде и сохраняется при обычном выходе клиента.
Он не содержит ник, учётные данные, бинды и настройки диагностических логов.
